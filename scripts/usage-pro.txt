webai2api 使用说明

1. 双击 webai2api.exe，会自动启动服务并弹出管理面板窗口
   （若没弹出，浏览器访问 http://127.0.0.1:8800/admin，默认密码 admin）
2. 「账号」页 →「添加账号」→ 只填名称 → 保存
3. 点该账号的「浏览器登录」，在弹出的内置浏览器里登录你自己的 AI 账号
   （DeepSeek / 智谱清言 / Kimi / 通义千问均可，凭证自动保存）
4. 「API Key」页 →「生成 Key」，复制这个 sk- 开头的 Key
5. 在 opencode 接入（设置 → 提供商 → 自定义提供商）：
     提供商 ID : webai2api
     基础 URL  : http://127.0.0.1:8800/v1
     API 密钥  : 你生成的 sk-...
6. 保存后在模型列表选对应模型即可使用（四家均支持工具调用与联网搜索）

说明：Base URL 永远是 http://127.0.0.1:8800/v1 —— 127.0.0.1 指"运行本软件的这台电脑"。
      别人在他自己电脑上跑本软件，也填这个（各用各的，互不依赖，跟你无关）。
内置浏览器是软件内的 WebView2 窗口，不调用你的 Edge/Chrome，也不会影响你日常浏览器的登录。
数据（账号/Key/用量）保存在同目录 data 文件夹，删除即重置。
端口默认 8800，被占用会自动更换（见 current_port.txt）。
仅供个人学习与本地自用，请勿公开分发或对外提供服务。
